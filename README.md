# Liguid-glass

مرجع رابط کاربری **WooGit Liquid Glass V1**.

## معرفی

این پروژه یک نمونه رابط کاربری موبایل‌محور، راست‌به‌چپ و فارسی برای نمایش ساختار Liquid Glass است. هدف آن ایجاد یک مرجع بصری برای ادامه طراحی رابط WooGit است.

## ساختار رابط

- هدر بالای صفحه با نام «ووگیت»، نشان اتصال فروشگاه و دکمه منو
- محتوای اصلی به صورت Feed عمودی و قابل اسکرول
- کارت اعلان سفارش جدید
- کارت وضعیت همگام‌سازی فروشگاه
- بخش محصولات اخیر
- کارت محصول
- کارت آمار فروشگاه
- دکمه مشاهده داشبورد
- نوار ناوبری پایین با خانه، محصولات، سفارش‌ها و تنظیمات

## اصول چیدمان

ارتفاع کارت‌ها ثابت نیست و هر کارت بر اساس محتوای واقعی خود ارتفاع می‌گیرد.

تمام عناصر اصلی Feed در جریان عادی صفحه قرار دارند؛ بنابراین هر کارت نسبت به کارت قبلی جایگذاری می‌شود و تغییر ارتفاع یک کارت باعث جابه‌جایی خودکار عناصر بعدی می‌شود.

فاصله بین آیتم‌های Feed منظم است و برای جلوگیری از بیرون‌زدگی متن، محتوای متنی امکان شکستن خط دارد.

## Liquid Glass

ظاهر شیشه‌ای با ترکیبی از موارد زیر ساخته شده است:

- شفافیت چندلایه
- `backdrop-filter: blur()`
- افزایش saturation
- حاشیه نیمه‌شفاف
- سایه‌های چندلایه
- هایلایت داخلی و sheen
- پس‌زمینه‌های رنگی شعاعی
- گوشه‌های گرد بزرگ
- افکت‌های حرکتی و pulse

این نسخه در حال حاضر یک پیاده‌سازی پیشرفته Glassmorphism است و هنوز تمام ویژگی‌های Liquid Glass سطح سیستم‌عامل، مانند شکست نور واقعی، displacement/refraction و chromatic aberration را پیاده‌سازی نکرده است.

## Responsive و Accessibility

- طراحی با اولویت موبایل
- حداکثر عرض مرجع 430px
- پشتیبانی از RTL
- اسکرول عمودی برای Feed
- پشتیبانی از `prefers-reduced-motion`

## وضعیت نسخه فعلی

نسخه فعلی یک **UI Reference / Prototype** است و برای استفاده به عنوان مرجع طراحی Liquid Glass آماده شده است.
